# JobTrack — Online Job Application Tracker

A beginner/intermediate college project built with only HTML, CSS and JavaScript.

## Features
- Dashboard with statistics and application pipeline
- 8 demo applications
- Add, edit and delete applications
- Search, status filters and sorting
- Application details modal
- Interview tracker
- Reminders
- Saved jobs
- Favorite applications
- Analytics using CSS/JavaScript bars
- Toast notifications
- LocalStorage persistence
- Responsive desktop/tablet/mobile layout
- Optional dark mode

## Run
Open `index.html` directly in a browser. No Node.js, backend, database or build step is required.

## Presentation concepts
HTML structure, CSS Grid, Flexbox, DOM manipulation, event listeners, forms, filtering, sorting, modals, LocalStorage, responsive design and simple JavaScript-generated analytics.
